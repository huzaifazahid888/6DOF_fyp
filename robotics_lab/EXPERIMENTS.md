# Experiment log

## Baseline preparation — 10 November 2026

The arm description was extracted from the V-REP scene. Mesh references, XML/YAML syntax, Python syntax, and joint names were checked offline. The original URDF forward kinematics matched the parsed scene chain over 101 configurations. The integrated Gazebo launch has yet to be tested.

- Algorithm and parameters
- Sensor settings and update rates
- Steps to reproduce
